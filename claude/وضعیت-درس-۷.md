## ۲ · ⭐ دستاورد اصلی: «یک قانون، چهار فعل»

خودش رسید به اینکه `wurde` گذشته‌ی `werden` است و `wuerde` فرضیِ آن — و دید همین الگو روی هر چهار فعل پرکاربرد سوار است. نقل‌قول خودش: **«این یه قانون و چهار تا فعل.»**

| حال | گذشته | فرضی |
|-----|--------|-------|
| kann | konnte | koennte |
| hat | hatte | haette |
| ist | war | waere |
| wird | wurde | wuerde |

یعنی `wuerde` که در درس ۶ یک چیز جدا به‌نظر می‌رسید، **استثنا نبود**.

## ۳ · 🧬 فاکتور کلی — چهار خط + نُه کلمه

| # | قانون |
|---|--------|
| ① | **فرضی = گذشته + اوملات.** اوملات نداشت؟ همان گذشته می‌ماند |
| ② | **در گذشته و فرضی:** `ich` = `er` · جمع = مفرد + `(e)n` — بدون استثنا |
| ③ | **مدال در حال:** `ich` = `er` بدون پسوند · جمع = خودِ مصدر (پس اوملات دارد) |
| ④ | **غیرمدال در حال:** اتاق‌ها فرق دارند — `werde` / `wird` |

**نُه کلمه‌ای که باید حفظ شود:** `konnte` · `musste` · `durfte` · `mochte` · `wollte` · `sollte` · `hatte` · `war` · `wurde`

### 🔑 جدول مرجع

| مصدر | حالِ `ich`/`er` | گذشته | فرضی |
|-------|------------------|--------|-------|
| koennen | kann | konnte | koennte |
| muessen | muss | musste | muesste |
| duerfen | darf | durfte | duerfte |
| moegen | mag | mochte | moechte |
| wollen | will | wollte | **wollte** ⚠️ همان شکل |
| sollen | soll | sollte | **sollte** ⚠️ همان شکل |
| haben | hat | hatte | haette |
| sein | ist | war | waere |
| werden | wird | wurde | wuerde |

## ۴ · قانون‌های تازه با برچسب اعتبار

| اعتبار | قانون |
|---------|--------|
| 🟢 | در گذشته `ich` = `er` — برای **همه‌ی** فعل‌ها |
| 🟢 | در حال فقط ۷ کلمه `ich`=`er`: ۶ مدال + `wissen` ⚠️ با لیست «بدون `zu`» (۶ مدال + `werden`) قاطی نشود |
| 🟢 | جمعِ گذشته = مفرد + `(e)n` |
| 🟢 | مدال در گذشته اوملات ندارد؛ در حال فقط **مفردش** اوملات را می‌اندازد، **جمعش نگه می‌دارد** |
| 🟢 | گذشته + اوملات = غیرواقعی (مؤدبانه یا فرضی) |
| 🟢 | اوملات دو نوع است: 🧬 ذاتی و ⚙️ دستوری. **فعل‌ها هم ذاتی دارند** — «فعل ⟵ دستوری» غلط است |
| 🟢 | خودش فقط **دو جا** اوملات اضافه می‌کند: فعل قوی `du`/`er` · فرضی از گذشته. جز این، همیشه بنویسدش |
| 🟢 | فعل قوی: `a`/`o`/`au` ⟵ اوملات · `e` ⟵ `i`/`ie` (اوملات نیست) |
| 🟢 | `nicht` آخرین کلمه قبل از خانه‌ی ته جمله 🏠؛ خانه خالی ⟵ آخر جمله. جلوتر گذاشتنش تأکیدی می‌کند |
| 🟢 | در جمله‌ی اصلی، فاعل یا جای اول است یا **بلافاصله بعد از فعل صرف‌شده** — هیچ‌چیز بینشان نمی‌نشیند |
| 🟢 | فعلِ ته **جمله‌ی فرعی** صرف‌شده است 👔، نه لخت |
| 🟢 | ADUSO فقط پنج کلمه · هر رابط دیگری تغییردهنده |
| 🟢 | `ohne` همیشه Akkusativ |
| 🟢 | لیست «بدون `zu`» = ۶ مدال + `werden` + **`lassen`**. افزوده‌ی آخر: `sehen`/`hoeren` در B1 |
| 🟢 | `sollen` = وظیفه‌ای که دیگری تعیین کرده · `muessen` = اجبار درونی/شرایط · `sollte` = توصیه یا گذشته |
| 🟢 | `duerfen` = فقط اجازه. «قادر بودن» مالِ `koennen` است |
| 🟢 | اگر فعل خودش شکل فرضی دارد، مستقیم از آن استفاده کن؛ `wuerde` فقط برای فعل‌هایی که نمی‌توانند |
| 🟡 | TeKaMoLo: زمان قبل از مکان — جزوه بعضی جا برعکس نوشته |
| 🟡 | `duerfte` درست است ولی کم‌کاربرد — `duerfen` از قبل مؤدبانه است |
| 🟡 | `wurde` فعلاً فعالانه استفاده نمی‌شود؛ کاربرد واقعی (مجهول) در فاز ۲ |
| 🟡 | `ei` ⟵ `ie` نشانه‌ی گذشته در خانواده‌ای از فعل‌های قوی (`bleiben`→`blieb`) — لیست کامل در فاز ۲ |

### 🔧 دو تصحیح که **خودش** باعثشان شد

| مورد | چه اشتباه بود | چطور لو رفت |
|-------|----------------|--------------|
| تست دو قدمی | «`-te-` دارد؟» — ولی `war` و `wurde` `-te-` ندارند | سؤالِ «`wuerden`؟» |
| ستون جدول مرجع | «حال» — در واقع «حالِ `ich`/`er`» بود | «چرا `will` برای دوم‌شخص؟» |

## ۵ · ⚠️ «یک حرف، دو معنی» — هشت جفت

| A | معنی | B | معنی |
|---|------|---|------|
| konnten | توانستند | koennten | می‌شود…؟ |
| mochte | دوست داشتم | moechte | مایلم |
| will | می‌خواهد | wird | خواهد داد |
| soll | قرار است | sollte | بهتر است |
| bleiben | ماندن | blieben | ماندیم |
| teuer | گران | tuer | در (Tür) |
| man | آدم | Mann | مرد |
| sie | او | Sie | شما |

قابِ آرامش‌بخشی که پذیرفته شد: **آلمانی سخت‌گیر است ولی قابل پیش‌بینی** — برخلاف انگلیسی. و در مکالمه زمینه نجات می‌دهد؛ این‌ها برای آزمون کتبی مهم‌اند.

## ۶ · پروفایل خطا

| خطا | دفعات | وضعیت |
|------|-------|--------|
| **خوشه‌ی همخوان** (`beliben` · `kontten` · `gerten` · `verechten` · `beilen`) | ۵ | 🔴 خطای شماره‌ی یک. ریشه: فارسی خوشه‌ی آغازین ندارد |
| **`ei`/`ie`** (`heir` · `blieben`) | ۵ | 🔴 **تنها خطایی که با توضیح حل نشد** — تمرین جدا در فایل مرور |
| حرف بزرگ اول جمله | ۴ | ⚠️ سرعت |
| حذف اوملات | ۳ | ⚠️ |
| TeKaMoLo — مکان قبل از زمان | ۲ | ⚠️ |
| شکل `ihr` به‌جای `ich`/`er` (`werde` · `duerft`) | ۲ | ✅ بهتر از درس ۶ (۵ بار) |
| انتخاب مدال عوضی | ۲ | زیر خستگی |
| `eu` در برابر `ue` (`tuer`) | ۱ | ⚠️ خطرناک |
| `Sie` با s کوچک | ۱ | ✅ بهتر |
| ویرگول قبل از بخش `zu` | ۲ | ⚠️ |
| `zehr` به‌جای `sehr` | ۱ | گوشش درست شنیده بود |

### ✅ خطاهای درس ۶ که این بار نباخت
`aber` را چسب نگه داشت (قبلاً ۲ بار) · `sein` کنار صفت (قبلاً ۴ بار) · `ihn`/`ihr` — پرونده‌ی باز بسته شد

### 😴 الگوی خستگی
همخوان سه‌برابر (`habbben`) · فاعل و مفعول جابه‌جا · **سرریز کلمات از جمله‌ی قبلی** · خراب‌شدن جمله‌ای که ده دقیقه قبل درست زده. هر دو بار بعد از ~۴۵ دقیقه کار پیوسته.

## ▶️ جلسه‌ی بعد — درس ۸

جزوه‌اش هنوز آپلود نشده.

**گرم‌کردن پیشنهادی (سه جمله):** یکی با `koennten` (فرضی) · یکی با `sollen` در برابر `muessen` · یکی با `bleiben` یا `hier` — چون `ei`/`ie` پنج بار لغزید.

### نکته‌های باز
- 🔴 **`ei`/`ie` تنها خطای حل‌نشده است.** فایل مرور یک تمرین روزانه‌ی پنج‌کلمه‌ای برایش دارد (`hier` · `bleiben` · `nein` · `mein` · `heute`). هر جلسه یک بار چک شود
- خودش ۲۱ شهریور خواست که مسیر «علمی و با پایه» باشد و آینده‌نگر — بندهای ۰ و ۹ سند سبک از همین درآمد. **هر مبحث از این به بعد اسم فنی هم می‌گیرد**
- در نقشه‌ی راه جلوتر از برنامه است: `Präteritum` (هفته ۱–۲) و `Konjunktiv II` (هفته ۷) هر دو در هفته‌ی ۱ پوشش داده شدند
