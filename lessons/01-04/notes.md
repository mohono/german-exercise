# جزوه‌ی آلمانی — روش میشل توماس (درس ۱ تا ۴)

> خلاصه‌ی کامل نکات، قواعد و گرامر — استخراج‌شده از جلسات کلاس و بحث‌های تکمیلی.
> این فایل برای استفاده به‌عنوان مرجع در پروژه‌های کلاد ساخته شده.

---

## 🔑 قانون طلایی (پایه‌ی همه‌چیز)

**V2 — فعل همیشه جای دوم است**

در جملات خبری آلمانی، فعل صرف‌شده همیشه عنصر دومِ جمله است (نه لزوماً کلمه‌ی دوم، بلکه جایگاه دوم).

```
Ich  trinke  Kaffee.
①فاعل ②فعل    بقیه
```

اگر جمله را با چیز دیگری (زمان/مکان) شروع کنی، فاعل و فعل جابه‌جا می‌شوند، ولی فعل همچنان دوم می‌ماند:

```
Morgen  fahre  ich  nach Berlin.
زمان    ②فعل   فاعل   مکان
```

---

## 🧱 ساختارهای قفل‌شده در برابر آزاد

فهمِ کلیدی کل زبان: بعضی چیزها ثابت‌اند، بعضی انعطاف دارند.

### 🔒 قفل‌ها (هیچوقت تکون نمی‌خورن)
- فعل جای دوم (V2)
- فعل کمکی → فعل اصلی به آخر جمله می‌رود
- بعد از weil / wann / warum / wo / dass → فعل به آخر می‌رود

### 🔄 آزادها (تأکید را عوض می‌کنند)
- قیدها (زمان، مکان، حالت) — جایشان کمی جابه‌جا می‌شود
- جای `nicht` — بستگی دارد چه چیزی را منفی کند

> **تشبیه:** جمله مثل یک اتاق است. دیوارها (فعل، ساختار) ثابت‌اند؛ مبل‌ها (قیدها) جابه‌جا می‌شوند و فقط حس فضا عوض می‌شود.

---

## 📐 ترتیب کلی اجزای جمله

```
[عنصر اول] + فعل + Dativ + Akkusativ + زمان + دلیل + حالت + مکان + [فعل اصلی/آخر]
```

### قانون TeKaMoLo (برای چیدن چند قید)
| حرف | معنی | مثال |
|-----|------|------|
| **Te** | زمان (temporal) | heute, morgen, jetzt |
| **Ka** | دلیل (kausal) | wegen... |
| **Mo** | حالت/روش (modal) | gern, mit dem Auto |
| **Lo** | مکان (lokal) | hier, dorthin |

> نکته: در جمله‌های ساده‌ی مبتدی معمولاً یکی دو قید بیشتر نداری، پس فعلاً فقط بدان **زمان زودتر از بقیه می‌آید**.

---

## 🎯 فعل کمکی + فعل اصلی

با فعل‌های کمکی (`wollen, können, müssen, möchte, werden`):
**فعل کمکی دوم می‌آید، فعل اصلی به آخر جمله می‌رود.**

```
Ich  will   heute hier  bleiben.
     ②کمکی            فعل اصلی (آخر)

Ich  kann   Sie   nicht  verstehen.
     ②کمکی               فعل اصلی (آخر)
```

## 👥 صرف افعال (Konjugation)

### الگوی باقاعده: ریشه + پسوند
مصدر را بگیر، `-en` را بردار تا «ریشه» بماند، بعد پسوند بچسبان.

| ضمیر | پسوند | مثال (bleiben → bleib) |
|------|-------|------------------------|
| ich | -e | bleibe |
| du | -st | bleibst |
| er/sie/es | **-t** | bleibt |
| wir | -en | bleiben |
| ihr | -t | bleibt |
| Sie/sie | -en | bleiben |

**استثنا:** اگر ریشه به `t` یا `d` ختم شود، یک `e` وسط می‌آید تا تلفظ ممکن شود:
```
warten → wart + t → wartet (نه wartt)
kosten → kost + t → kostet
```

### افعال بی‌قاعده‌ی مهم

**werden (آینده):** ریشه‌اش عوض می‌شود (e → i)
| ich werde | du wirst | er/sie/es **wird** | wir werden | Sie werden |

**wissen (دانستن):** با ich و er می‌شود `weiß` (بدون t!)
```
ich weiß / er weiß / Sie wissen
```

## ⏩ زمان آینده

دو راه دارد:

**۱. با werden:** (مثل فعل کمکی رفتار می‌کند)
```
Ich werde es morgen haben.   (werden دوم، haben آخر)
```

**۲. با فعل حال + قید زمان:** (وقتی زمان مشخص باشد، خود حال کافی است)
```
Ich sehe Sie morgen.   →  فردا می‌بینمت
```
> دقیقاً مثل فارسی: «فردا میام» به‌جای «فردا خواهم آمد».

## 🎭 Akkusativ و Dativ

| | نقش | سؤال | مثال |
|---|-----|------|------|
| **Akkusativ** | مفعول مستقیم | چه چیزی/کسی را؟ | mich (من را)، es (آن را)، Sie (شما را) |
| **Dativ** | مفعول غیرمستقیم | به چه کسی؟ | mir (به من)، Ihnen (به شما) |

### ترتیب دو مفعول
**قاعده کلی: Dativ قبل از Akkusativ**
```
Ich gebe dem Mann das Buch.   (Dativ → Akkusativ)
```

**استثنای مهم:** اگر Akkusativ یک **ضمیر** باشد، اول می‌آید:
```
ich kann es Ihnen bringen.   (es ضمیر است → قبل از Ihnen)
```

خلاصه:
- Akkusativِ ضمیر (es) → اول
- Akkusativِ اسم (das Buch) → بعد از Dativ

> **ضمیر** = جایگزین اسم (es, mich, dich). **اسم** = خود کلمه (das Buch, der Kaffee).

---

## ❌ جای nicht

**قاعده‌ی اصلی:** `nicht` درست قبل از چیزی می‌آید که می‌خواهد منفی کند.

- **nicht آخر جمله (قبل از فعل):** کل جمله را منفی می‌کند
- **nicht جلوی یک کلمه‌ی خاص:** فقط همان کلمه را منفی/محدود می‌کند

```
Ich gehe nicht dorthin.   →  به آنجا نمی‌روم (کل جمله)
Ich gehe nicht heute.     →  امروز نه (فقط زمان، شاید روز دیگر)
```

مثال از تفاوت تأکید:
```
nicht so möglich   →  آن‌طور ممکن نیست (روش)
so nicht möglich   →  این‌جوری نه (روش دیگر)
```

## 🔗 حروف ربط: denn در برابر weil

**هر دو یعنی «چون»، ولی ساختارشان کاملاً فرق دارد:**

```
denn:  ..., denn ich bin müde.      →  فعل سر جایش (دوم) ✅
weil:  ..., weil ich müde bin.      →  فعل به آخر می‌رود!
```

### ⭐ weil با فعل کمکی (سخت‌ترین نکته)
فعل کمکی که همیشه دوم بود، در weil به **تهِ همه‌چیز** می‌رود — حتی بعد از فعل اصلی:

```
جمله عادی:  ich kann Sie nicht verstehen.
با weil:    ..., weil ich Sie nicht verstehen kann.
                              فعل اصلی ← کمکی(آخر)
```

نمونه‌ها:
```
weil ich sehr beschäftigt sein werde     →  werde آخر
weil ich mit Ihnen nicht kommen kann     →  kann آخر
weil ich es haben muss                   →  muss آخر
```

---

## 🧩 جمله‌های فرعی (Nebensatz) — تعمیم بزرگ

**نه فقط weil!** هر جمله‌ی فرعی فعلش به آخر می‌رود.

### چه کلمه‌هایی فعل را به آخر می‌فرستند؟
- **حروف ربط:** weil (چون)، dass (که)، wenn (اگر)
- **کلمه‌های پرسشی وقتی وسط جمله بیایند:** wann, warum, wo, wieviel, um wie viel Uhr

```
سؤال مستقل:  Wann kann ich es haben?          →  kann دوم
داخل جمله:   ..., wann ich es haben kann.      →  kann آخر
```

نمونه‌ها:
```
ich will wissen, wieviel es kostet.               →  kostet آخر
ich will wissen, wann ich es haben kann.          →  kann آخر
..., warum ich es machen muss.                    →  muss آخر
..., um wie viel Uhr ich es haben kann.           →  kann آخر
```

> **استثنا:** `denn` این کار را نمی‌کند! فعل را سر جایش می‌گذارد.

### راه ساده‌ی تشخیص
اگر جمله‌ای را با ویرگول چسباندی و با این کلمه‌ها شروع شد → فعلش آخر:
`weil, dass, wann, warum, wo, wieviel...`

---

## 🗣️ جمله‌ی امری (Imperativ)

برای دستور/خواهش مؤدبانه به یک نفر (Sie): **ساختار مثل جمله‌ی سؤالی، فعل اول می‌آید — فقط لحن فرق می‌کند.**

```
Bringen Sie es mir?   →  می‌آورید؟   (سؤال)
Bringen Sie es mir!   →  بیاورید!    (امر)
Warten Sie bitte!     →  لطفاً منتظر بمانید!
```

## 🧭 حرکت در برابر ثبات (مفهوم تکرارشونده)

آلمانی بین «بودن در جایی» و «رفتن به سمتی» تفاوت می‌گذارد:

| ثابت (کجا هستی؟) | حرکت (به کجا؟) |
|------------------|----------------|
| wo (کجا) | wohin (به کجا) |
| dort (آنجا) | dorthin (به آنجا) |
| hier (اینجا) | hierher (به اینجا) |
| zu Hause (در خانه) | nach Hause (به سمت خانه) |

```
Ich bleibe zu Hause.   →  در خانه می‌مانم (ثبات)
Ich gehe nach Hause.   →  به سمت خانه می‌روم (حرکت)
```

### hin و her (جهت)
- **hin** = به سمتِ دور از من
- **her** = به سمتِ من (به طرف گوینده)

```
Kommen Sie hierher!    →  بیایید اینجا (به سمت من)
Ich will dorthin gehen. →  می‌خواهم به آنجا بروم (دور از من)
```

### شکستن wohin
`wohin = wo + hin`. می‌توانی نصفش کنی: `wo` اول جمله، `hin` بچسبد به فعل حرکت:
```
Wohin wollen Sie gehen?      (چسبیده)
Wo wollen Sie hingehen?      (جدا: hin روی gehen)
```
هر دو یک معنی دارند. (hin به **فعل حرکت** می‌چسبد، نه به wo.)

## 🤝 فعل + حرف اضافه‌ی ثابت

بعضی فعل‌ها یک حرف اضافه‌ی مشخص همراهشان است که باید حفظ شود.

**مثال کلیدی: warten auf (منتظرِ ... بودن)**
- حرف اضافه (`auf`) را **فعل** تعیین می‌کند، ولی کنار **ضمیر/اسم** می‌نشیند.
- `auf` در این ساختار **Akkusativ** می‌خواهد → `auf mich` (نه auf mir)

```
Warten Sie auf mich!         →  منتظر من باشید!
Wollen Sie auf mich warten?  →  (auf mich یک بسته است، با هم جابه‌جا می‌شود)
```

> **Tip ماندنی:** `warten auf + Akkusativ` → `Ich warte auf dich.`
> فعل حرف اضافه‌اش را انتخاب می‌کند، ولی آن حرف اضافه کنار ضمیر می‌نشیند و همیشه با هم جابه‌جا می‌شوند. 📦 هیچوقت `auf mich` را از هم جدا نکن.

## 😊 möchte و gern (بیان ادب و علاقه)

### möchte — مؤدبانه‌ترین «می‌خواهم»
```
ich will    →  می‌خواهم (مستقیم، گاهی خشک)
ich möchte  →  مایلم / دوست دارم (مؤدب)
```
مثل فعل کمکی رفتار می‌کند: `ich möchte es sehen` (möchte دوم، sehen آخر).

### gern — «با میل / با لذت»
آلمانی فعلِ جدا برای «دوست داشتنِ انجام کاری» ندارد؛ به‌جایش `gern` را کنار فعل می‌گذارد:
```
ich tue es       →  انجامش می‌دهم
ich tue es gern  →  با میل انجامش می‌دهم / دوست دارم انجامش بدهم
```

**تفاوت möchte و gern:**
| | معنی |
|---|------|
| ich möchte es tun | الان مایلم انجامش بدهم (یک‌بار، الان) |
| ich tue es gern | کلاً دوست دارم انجامش بدهم (عادت/لذت) |

**نکته‌ی مهم درباره‌ی gern:**
- `gern` یک **قید** است، هیچوقت صرف نمی‌شود، همیشه `gern` می‌ماند.
- فعل همچنان جای دوم است (V2). gern قید است و بعد از فعل می‌آید.
- جایش انعطاف دارد: `ich gehe dorthin gern` ✅ و `ich gehe gern dorthin` ✅ هر دو درست‌اند (فقط تأکید فرق می‌کند).
- ولی gern نمی‌تواند فعل را از جای دوم بیندازد: ❌ `gern ich gehe...` / ❌ `ich gern gehe...`
- بعد از مفعولِ ضمیر (es)، قید بعدش طبیعی‌تر است: `ich sehe es gern`.

## 🔤 کلمات مشابه که قاطی می‌شوند

| کلمه ۱ | کلمه ۲ | تفاوت |
|--------|--------|-------|
| **schon** (از قبل / دیگر) | **schön** (زیبا) | فقط دو نقطه (Umlaut)! تلفظ: شُون / شؤن |
| **beschäftigt** (مشغول) | **das Geschäft** (مغازه) | هم‌ریشه‌اند (کار/کسب) |
| **kaufen** (خریدن) | **der Kaufmann** (تاجر) | هم‌ریشه |
| **möglich** (ممکن) | **unmöglich** (ناممکن) | un = منفی‌ساز (مثل انگلیسی) |
| **alles** (همه‌چیز، اشیا) | **alle** (همه، افراد) | مفرد در برابر جمع |

### alles / alle
از حرف تعریف پسوند می‌گیرند:
```
das → alles   (همه‌چیز، مفرد)  →  alles bleibt / alles ist fertig
die → alle    (همه، جمع)       →  alle bleiben hier
```
ترکیب‌ها: `wir alle` (همه‌ی ما)، `Sie alle` (همه‌ی شما).

> **ترفند نشانه‌ی حرف تعریف:** جانشین‌های حرف تعریف پسوند حرف تعریف را می‌گیرند (das→alles/dieses، die→alle/diese، der→aller/dieser). این ترفند برای جانشین‌ها جواب می‌دهد، **نه** برای صفت‌های بعد از حرف تعریف (das gute Buch، نه das gutes Buch) — که هنوز نخوانده‌ای.

### so — چندمعنایی
```
so → آن‌طور / این‌طور   (روش)
so → آنقدر / خیلی       (درجه)
```
معنی را از جمله بفهم، نه تنها.

## ⚠️ تذکرهای مهم درباره‌ی جزوه‌ی کلاس

چند مورد در جزوه که می‌توانند گیج‌کننده باشند:

1. **ترجمه‌های تایپی:** جاهایی «بیاییم/بگوییم» نوشته که باید «بیایم/بگویم» باشد (اول‌شخص مفرد). آلمانی‌اش درست است.
2. **غلط تایپی آلمانی:** `um wir viel Uhr` باید `um wie viel Uhr` باشد (`wir` اشتباه است).
3. **`alles bleibt hier`** درست است (نه bleiben)؛ ترجمه‌ی فارسی «می‌مانند» کمی نادقیق است، باید «می‌ماند» باشد.
4. **جمله‌ی `wollen Sie bitte auf mich morgen hier warten?`** ترتیبش به‌خاطر روش قدم‌به‌قدم است؛ استانداردترش: `wollen Sie bitte morgen hier auf mich warten?`
5. **`Er ist sehr schön`** گرامری درست است ولی برای مرد معمولاً schön به کار نمی‌رود.

## 🧠 خلاصه‌ی طلایی (اگر فقط چند چیز را حفظ کنی)

1. **فعل دوم است (V2)** — مهم‌ترین قانون.
2. **فعل کمکی دوم، فعل اصلی آخر.**
3. **weil فعل را به آخر می‌فرستد، denn نمی‌فرستد.**
4. **جمله‌ی فرعی (weil/wann/warum/...) = فعل آخر.**
5. **Dativ قبل از Akkusativ — مگر Akkusativ ضمیر باشد.**
6. **حرکت در برابر ثبات:** wohin/nach Hause در برابر wo/zu Hause.
7. **قیدها انعطاف دارند؛ ساختار (فعل) قفل است.**
8. **حال + قید زمان = آینده.**
